무료 · 오픈소스 (AGPL-3.0)

ch-manage 설치 가이드

교회 교적 관리 프로그램을 내 호스팅에 설치하는 방법 — 컴퓨터를 잘 몰라도 따라 할 수 있게 순서대로 적었어요.

예상 시간: 30분 안팎 · 필요한 것: 호스팅 계정, 컴퓨터(윈도우/맥), 이 프로그램의 zip 파일

0. 시작하기 전에

호스팅웹 호스팅 한 곳이 필요해요. 카페24 같은 국내 일반 웹호스팅이면 충분하고, 가장 저렴한 상품으로도 돌아가요. 아래 세 가지가 되는지만 확인하세요.
필수 조건① PHP 8.1 이상   ② MariaDB 또는 MySQL 데이터베이스 1개   ③ Apache (보통 기본 제공)
주소도메인 맨 위(https://example.com/)에 설치해도 되고, 폴더(https://example.com/cm/)에 설치해도 돼요. 설치 프로그램이 알아서 맞춰요.
보안꼭 https(자물쇠 표시) 주소로 쓰세요. 교인 정보가 들어가는 프로그램이에요.
개인정보 안내 — 교인의 이름·연락처·주소·사진, 그리고 신앙 정보(세례·직분)는 민감한 개인정보예요. 사용하는 교역자와 담당자에게 필요한 만큼만 권한을 주세요. 이 프로그램은 교회가 자기 호스팅에 직접 설치해서 쓰므로 자료는 교회 서버에만 저장돼요.

1. 데이터베이스 만들기

프로그램의 모든 자료가 들어갈 '창고'예요. 호스팅 관리 화면에서 만들고, 아래 네 가지 정보를 메모해 두세요.

  • 접속 주소 (카페24는 보통 localhost)
  • 데이터베이스 이름
  • 데이터베이스 아이디
  • 데이터베이스 비밀번호

카페24의 경우

  1. 카페24 로그인 → 마이페이지(나의 서비스 관리) → 사용 중인 호스팅의 관리로 들어가요.
  2. 메뉴에서 DB 관리 또는 MySQL(DB) 정보 비슷한 이름의 항목을 찾아요. 이미 만들어진 DB의 이름·아이디가 보이고, 비밀번호는 여기서 새로 정할 수 있어요.
  3. 이 정보를 적어 둬요. (화면 이름은 카페24가 바꿀 수 있어요. 못 찾겠으면 호스팅 고객센터에 "MySQL 접속 정보를 알려주세요"라고 물어보면 돼요.)
같은 데이터베이스에 다른 프로그램(홈페이지, 부서 관리 dep-manage 등)이 이미 있어도 괜찮아요. 이 프로그램의 표 이름 앞에는 cm_이 붙어서 섞이지 않아요.

2. 파일 올리기

  1. 내려받은 ch-manage-버전.zip 파일을 컴퓨터에서 압축을 풀어요. (우클릭 → 압축 풀기)
  2. FTP 프로그램(예: FileZilla)으로 호스팅에 접속해요. 접속 정보는 호스팅에서 알려준 FTP 주소·아이디·비밀번호예요.
  3. 카페24는 www 폴더가 웹사이트의 맨 위예요. 폴더에 설치하려면 www 안에 새 폴더(예: cm)를 만들어요.
  4. 압축을 푼 폴더 안의 내용 전부(index.html, _app, api, install, migrations, data 등)를 방금 정한 위치에 올려요. 폴더 자체가 아니라 안에 든 것들이에요.
  5. 올리는 데 몇 분 걸려요. 끝나면 index.html과 install 폴더가 같은 위치에 보여야 해요.
호스팅의 파일 관리자(웹FTP)에서 zip을 그대로 올리고 서버에서 압축을 풀 수 있다면 그 방법이 더 빨라요.

3. data 폴더에 쓰기 권한 주기

설치 정보를 저장할 수 있도록 data 폴더를 쓸 수 있게 해야 해요. FTP 프로그램에서 data 폴더를 우클릭 → 파일 권한(속성) → 숫자 값에 707 (안 되면 777)을 넣어요. 대부분의 호스팅은 이미 되어 있어서 건너뛰어도 돼요. 설치 화면의 점검 단계에서 안 되면 알려 줘요.

4. 설치 화면 열기

  1. 브라우저에서 https://내주소/install/ (폴더에 설치했다면 https://내주소/cm/install/)을 열어요.
  2. 1환경 점검 — 모두 초록색 ✓ 이면 다음으로. 빨간 항목이 있으면 그 항목 설명대로 호스팅 설정을 바꾸거나 고객센터에 문의하세요.
  3. 2데이터베이스 — 1단계에서 메모한 정보를 넣어요. 접두어는 cm_ 그대로 두면 돼요.
  4. 3교회 정보 — 교회 이름과, 우리 교회에서 쓰는 말(큰 모임 이름: 교구·공동체 등 / 작은 모임 이름: 구역·소그룹·목장·셀 등)을 정해요. 나머지(교단, 주소, 로고, 직인)는 설치 뒤 관리자 메뉴에서 채워요.
  5. 4관리자 계정 — 교적 전체를 관리할 '최고관리자' 아이디와 비밀번호(8자 이상)를 만들어요. 잊어버리지 않게 적어 두세요.
  6. 끝나면 로그인하러 가기를 눌러 방금 만든 계정으로 들어가요.
설치가 끝나면 설치 화면은 다시 열리지 않아요(이미 설치됨 안내만 보여요). 설치 중 문제가 생기면 그 시도에서 만든 표는 자동으로 정리되니 처음부터 다시 해도 안전해요.

5. 처음 설정하기 (로그인 후)

  1. 샘플 데이터로 먼저 둘러보고 싶다면 대시보드의 샘플 데이터 불러오기를 눌러요. 만들어 낸 가상 교인이 들어가서 화면을 미리 볼 수 있어요. 실제로 쓰기 전에는 샘플을 지우고 시작하세요.
  2. 관리자 › 교회 설정 › 기본 설정에서 교회 이름, 로고, 직인(증명서용), 탭 아이콘(브라우저 탭과 제목 옆에 보이는 작은 그림)을 넣어요. 탭 아이콘을 넣지 않으면 파란 바탕의 십자가가 기본으로 보여요.
  3. 관리자 › 교회 설정의 연간 설정(절기·성례 일정), 교회 조직표, 소그룹 편성을 우리 교회에 맞게 고쳐요.
  4. 관리자 › 프로그램 설정에서 교인 구분, 코드표(직분·세례 등), 확인 목록을 정리하고, 백업(자동 백업 주기)을 확인해요.
  5. 함께 쓸 사람들은 로그인 화면의 가입 신청으로 신청하게 하고, 최고관리자가 관리자 › 회원에서 승인하면서 등급(A·B·C·D)을 정해요. 소그룹 인도자는 D 등급이에요(아래 6번).
  6. 교인 명단은 교인 목록에서 한 명씩 등록하거나 엑셀 양식으로 한꺼번에 올려요.

6. 등급 한눈에 보기

등급할 수 있는 일
최고관리자모든 기능 + 회원 승인·등급 변경, 교회·프로그램 설정, 교인 삭제, 백업, 부서 관리 연결
A 등급교적 보기·수정 + 심방 기록(심방은 A 등급만)
B 등급교적 보기·수정 (교인 삭제와 심방은 못 해요)
C 등급꼭 필요한 정보만 보기
D 등급소그룹 인도자 전용. 교적 화면은 열 수 없고, 자기가 인도하는 소그룹의 주일 출석 체크(특이사항·기타 의견 포함)만 해요
소그룹 인도자(D 등급) 만들기 — 인도자가 가입 신청을 하면 관리자 › 사용자 설정 › 가입 신청에서 등급을 D로 승인하고, 사용자 목록의 연결된 교인 칸에서 그 인도자를 교인으로 연결해 주세요. 그 교인이 인도자로 지정된 소그룹(관리자 › 교회 설정 › 소그룹 편성)만 인도자의 화면에 나와요.

등급별로 수정 · 내려받기·출력 · 사이트 관리 권한을 따로 줄 수 있어요. 누가 언제 무엇을 봤는지는 접속 기록에 남아요.

7. 백업과 업데이트

백업 (꼭 정기적으로)

최고관리자로 로그인 → 관리자 › 프로그램 설정 › 백업.

  • 지금 백업 내려받기 — 교인·출석·심방·사용자·접속 기록과 올린 사진이 파일 하나(.cmbak)로 내려와요. 비밀번호 정보도 들어 있으니 안전한 곳에만 보관하세요. 업데이트 전에는 꼭 받아 두세요.
  • 자동 백업 — 주기·시각·보관 개수를 정해 두면 서버가 알아서 백업해요. 호스팅의 예약 작업을 쓰지 않아서, 그 시각에 아무도 접속하지 않으면 다음 접속 때 만들어져요. 서버에 보관된 백업은 같은 화면의 목록에서 내려받거나 되살릴 수 있어요.
  • 백업 파일로 되살리기 — 파일을 고르면 내용을 확인해서 보여 주고, 비밀번호를 한 번 더 입력하면 지금 자료가 모두 그 백업의 내용으로 바뀌어요. 되살리기 직전의 자료는 서버에 자동으로 한 번 보관되고(목록의 '되살리기 직전'), 끝나면 모두 로그아웃돼요.
서버에 보관한 백업은 호스팅 안에 있어서, 호스팅 자체에 문제가 생기면 함께 잃을 수 있어요. 가끔은 지금 백업 내려받기로 내 컴퓨터에도 받아 두세요. 호스팅의 DB 백업 기능도 함께 쓰면 더 안전해요.

개인정보 정리

백업 화면 아래의 개인정보 정리에서, 전출·별세·제적 후 몇 년이 지나면 그 교인의 인적사항(연락처·주소·생년월일·직업·메모·사진·수정 이력)을 지울지 정해요. 이름·재적 이력·세례·직분 같은 교회 기록은 보관해요. 처음에는 5년으로 켜져 있어요(자동). 정리 직전의 자료는 서버에 한 번 보관돼요.

외부 서비스 (문자 발송, AI 분석) — 선택

관리자 › 프로그램 설정 › 외부 서비스에서 쓰고 싶은 기능만 연결해요. 연결하지 않은 기능의 버튼은 화면에 나타나지 않아요. 사용 요금은 각 서비스에 직접 내요.

  • 문자 보내기(솔라피) — solapi.com에 가입하고 발신번호를 등록한 뒤, API Key·API Secret과 발신번호를 넣어요. 교인 목록에서 검색한 사람들에게 보낼 수 있고(A 등급), 수신 거부한 사람은 자동으로 빠져요. 하루 3,000건까지예요.
  • AI 분석(구글 Gemini) — aistudio.google.com에서 API 키를 만들어 넣어요. 등록카드 사진을 읽어 교인 등록 칸을 채우고, 심방 녹음·문서를 분석해 심방 기록 칸을 채워요. 올린 사진·녹음은 분석을 위해 구글 서버로 전송돼요. 심방 내용에는 건강 같은 민감한 정보가 있을 수 있으니, 교인에게 알리고 동의를 받은 뒤 쓰세요.

새 버전으로 업데이트

  1. 먼저 위의 방법으로 백업을 받아요.
  2. 새 zip의 압축을 풀고, 안의 내용을 같은 위치에 덮어써서 올려요. (data 폴더의 설정은 새 zip에 없으니 그대로 남아요.)
  3. 브라우저에서 …/install/ 을 한 번 열어요. "화면 파일을 마무리했어요"라고 나오면 성공이고, 데이터베이스의 변경과 https 로 자동 이동하는 설정(.htaccess)도 이때 함께 적용돼요. 이 단계를 빼먹으면 새 화면이 제대로 보이지 않아요.
  4. 브라우저에서 강력 새로고침(Ctrl+F5)을 한 번 해 주세요.
  5. (0.2.0 이상) 서버에 보관되는 백업이 있다면 data/backups 폴더는 지우지 마세요. 업데이트 zip에는 들어 있지 않아 그대로 남아요.

8. 부서 관리(dep-manage)와 함께 쓰기

교회 부서를 관리하는 짝 프로그램 dep-manage를 같은 데이터베이스에 설치하면, 교육부서 학생·교사를 교인과 연결할 수 있어요. 이름·성별·생년월일·연락처·주소·세례는 교적에서 한 번만 고치면 부서 관리에도 반영되고, 부서·학년·반·출석은 부서 관리의 것을 교적 화면에서 볼 수 있어요. 최고관리자로 관리자 › 프로그램 설정 › 부서 관리 연결에서 연결할 후보 불러오기를 눌러 이름·생년월일이 같은 학생을 한꺼번에 연결하세요. 두 프로그램은 따로 써도 되고, 하나를 쓰다가 나중에 다른 하나를 추가해도 돼요.

9. 문제가 생겼을 때

증상확인할 것
설치 화면이 안 열리고 빈 화면 또는 오류PHP 버전이 8.1 이상인지 호스팅 설정에서 확인하세요. install 폴더가 올라갔는지도 확인하세요.
"data 폴더에 쓰기" 가 빨간색3번처럼 data 폴더 권한을 707 또는 777로 바꾸세요.
데이터베이스에 연결하지 못했어요접속 주소·이름·아이디·비밀번호를 다시 확인하세요. 비밀번호의 특수문자나 앞뒤 공백도 확인하세요.
로그인 화면은 뜨는데 주소를 직접 입력하면 "페이지 없음"사이트 맨 위 폴더에 .htaccess 파일이 있는지 확인하세요(점으로 시작하는 파일은 FTP 프로그램에서 '숨김 파일 보기'를 켜야 보여요). 없으면 …/install/ 을 한 번 열면 만들어져요.
화면이 하얗거나 글자만 나와요업데이트 후라면 …/install/ 을 한 번 여세요. 브라우저에서 강력 새로고침(Ctrl+F5)도 해 보세요.
"서버에서 문제가 생겼습니다 (404)"가 저장할 때 나와요호스팅이 한 번에 보내는 자료 크기를 제한하는 경우예요. 큰 사진을 올렸다면 줄여서 다시 올려 보세요. 계속되면 문의해 주세요.
사진·로고·직인이 올라가지 않아요호스팅에 GD 확장이 켜져 있는지 설치 화면의 점검 항목을 보세요. 파일이 너무 크면 줄여서 올려 보세요.
